# ITS TIME
DMA252A workshop repo

A  p5.js sketch that tells you what time it is and how you're feeling.

The sketch also randomly chooses:
- One of 30 emotions
- Background, text, and stroke colors
- One of five font sizes
- Whether the text rotates (10% chance)

Everything is determined when the page loads. Refresh to generate a new version.

## Files

- `index.html` — Loads p5.js and the sketch.
- `sketch.js` — Contains the clock, emotions, colors, typography, and animation.

## Run

Open `index.html` in a browser, or view the project through GitHub Pages.

## Fork & Hack

This sketch is a starting point for experimentation. You can fork the repository and change it into something else.

Some possibilities:
- Change the emotions
- Introduce new visual behaviors
- Change the relationship between time and feeling
- Break or misuse the clock's original logic

Commit your changes, publish your version, and consider opening a pull request
